# Restore verified public ending text before judging

An independent audit found that the existing cancellation recorder sometimes writes an empty assistant_text when public commentary precedes end_session in the same completed provider response. The function call is genuine; the recorder omission does not explain premature termination. In the completed cohorts inspected, these cases were early-ending conversations, so they do not enter the README's completed-only rows. They still need accurate public text for fixed-denominator judging.

Before freezing judge inputs, retrieve the stored completed provider response for each such recorded ending. Verify every public message and native function-call output-item hash against the capture-time wire audit. Restore only message content parts of type output_text in a derived judge view, identified by an exact hash of the original transcript record. Preserve original transcripts, raw logs, native audits, provider retrievals, tool records and latency. Do not infer text, synthesize answers, add reasoning, change the rubric, or retry an ending because of its quality.

Pre-grade retrieval qualification: a Terra medium response contained encrypted reasoning in the captured stream. Persisted-response retrieval omits that encryption and rejects include=reasoning.encrypted_content with HTTP 400, "Encrypted content cannot be requested for persisted responses." Its public message and function-call hashes match exactly. Allow this private-item mismatch only when the captured item is reasoning with encrypted content, the retrieved reasoning item lacks encryption, and its identity and all other recorded structural metadata match. Mark that private item's full hash unverified in the manifest; verify all public/function-call items exactly. Private reasoning is never restored or passed to the judge. All other mismatches still stop grading. This qualification was registered before any paid refresh grades.

The PUBLIC-TEXT-RESTORATIONS manifest pins the original transcript/record, provider response ID and retrieval hash, and recovered public text/hash. The ordinary private-reasoning filter runs after this exact restoration. Judge metadata records each normalized turn and the actual prompt hash. All raw source and snapshot hashes remain unchanged.
