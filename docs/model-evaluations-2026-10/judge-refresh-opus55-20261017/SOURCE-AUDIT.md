# Local source and configuration audit

Search completed October 18, 2026 before final publication. Scope: every retained README configuration, including unjudged and archived captures. The primary audit found **8,060 source transcript files, 7,370 distinct transcript byte hashes, 690 duplicate copies, 35 model families**, and no timestamp-ID conflicts or parse errors. Captures at different efforts, filler settings, precision, budget mechanisms, endpoint origins, sampling settings, or prompts remain distinguishable.

The search covered `/home/khkramer`, `/tmp`, `/mnt`, and `/media`, including ignored/hidden files, sibling worktrees, nested concurrency projects, the port-to-port checkout, Nemotron AWS/local projects, and local compressed archives. Some inaccessible unrelated system-owned directories yielded `rg` permission errors; no candidate source parse errors occurred. Nothing can establish the absence of captures on remote machines, deleted disks, or unavailable storage.

The primary discovery list contained 12,336 transcript/archive paths. A broader second pass inspected **31,868 transcript/conversation-like paths**, including 14,129 standard transcript files and 6,956 judged transcript files. Its 1,793 additional standard transcript paths were all new campaign snapshots or test fixtures. There were no complete orphan judged transcripts missing their original raw transcript. Other conversation-like JSON was prompt templates, request/response smoke traces, unrelated benchmarks, or visualization summaries, rather than additional complete scripted captures.

A filename-independent check also found **203 complete Qwen timing/DFlash files or copies outside benchmark-named folders**. These are later instrumentation/speculative-decoding studies: origins `localhost:30190`, `localhost:30200`, and an ephemeral client-test port, plus judge-input copies. None matches the selected production row's origin `localhost:30186` and governing configuration. Some contain a modified prompt/request instrumentation. They were explicitly checked against both retained Qwen 3.8 selection rules; every file has recorded exclusion reasons in [supplemental-source-audit.json (local archive)](../README.md). They do not change frozen membership or represent 203 independent new repetitions.

An additional whole-tree archive-name search found 735 archives. The two Nemotron raw-data archives below contain relevant original conversations. The two Ultra performance-report bundles contain report/visualization data, not transcripts; the step-attack profiling archive contains five profiling files, not conversations. Other matches are dependency packages, unrelated ASR/voice benchmarks, browser traces, build caches, and source backups. They do not supply matching medium-context conversations.

A final model-ID sweep checked aliases and metadata-first/empty transcripts. It found 277 empty files, 192 manual Nano diagnostic traces, and 105 other schema/blinded files; the only unnamed files with all 30 scripted indices were prior blinded judge-calibration copies. A fully qualified Lightning alias was an incomplete Modal diagnostic. Fourteen older Nano OpenRouter-free captures were a different route and budget configuration, not the selected native-budget AWS profile. No additional eligible source was found. Counts, paths, settings, and dispositions are in [model-alias-audit.json (local archive)](../README.md).

Local Git object histories across the evaluation repository, Nemotron AWS repository, and port-to-port repository were also checked across all refs. The 33 Nemotron transcript blobs already match the primary inventory; the four evaluation transcript blobs are the existing blinded calibration inputs, and port-to-port has no committed transcript blobs. The other 297 JSONL blobs are attempt ledgers, synthetic/timing probes, and port-to-port result summaries; none contains scripted `user_text`/`assistant_text` response records. No hidden source cohort was recovered from Git. See [git-source-audit.json (local archive)](../README.md).
